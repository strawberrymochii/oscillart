# oscillart

This project is my submission for Oscillart. Type in music note letters and see them transformed into sine wave art! I added features that allow users to choose however many gradient colors they want, and whether they want a filled wave.

This project was made using JavaScript , HTML and CSS. I followed the Oscillart tutorial by celesteroselli, and I also used online resources like W3School for my own additions to oscillart. I learned how to use JavaScript canvas and audio API, and I got to practice coding with JavaScript in general! The biggest challenge was definitely coding the gradient of the waves, especially figuring out the function that allows users to create new gradient color stops.
